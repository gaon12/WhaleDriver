# WhaleDriver 0.1.0

The first alpha release provides independent, unofficial Selenium support for
the desktop NAVER Whale browser. NAVER Whale belongs to NAVER Corporation.
WhaleDriver is not affiliated with, endorsed by, sponsored by, or supported by NAVER.
Project source code is licensed under BSD 3-Clause, the same license type as ChromeDriver.

## Included

- A Python Selenium API with `Whale`, `Options`, and `Service`.
- Installed-browser discovery and full Chromium engine version detection.
- Official ChromeDriver selection, verified caching, and offline operation.
- A CLI for diagnostics, installation, and a local WebDriver service.
- A Windows x64 portable distribution with ChromeDriver 150.0.7871.124, a Python
  runtime, project notices, and dependency license files.
- `build.cmd` and `build.ps1` for rebuilding after replacing ChromeDriver and its notices.

## Downloads and use

Extract the entire portable ZIP and run `whaledriver.exe doctor` or
`whaledriver.exe serve --port 9515 --offline`. Set the remote client's Chrome
options binary to the Whale path reported by the service. No Python installation
is required to run the extracted portable distribution. Compare the ZIP's SHA-256
hash with the attached `.sha256` file.

The wheel installs with `python -m pip install <wheel filename>`. The source
archive and repository provide the development and rebuild scripts.

## Verified compatibility

Real-browser testing used Windows x64, Whale 5.39.412.57, Chromium 150.0.7871.252,
and Selenium 4.50.0. The compiled service also passed a real headless Whale test
using its bundled backend. The portable driver requires Chromium major 150;
rebuild or provide another compatible driver when Whale changes engine majors.

Other desktop platforms have discovery and download support in the Python package
but have not been tested with real Whale here. This release has a Windows x64
portable asset only. Whale-specific UI and account features, mobile browsers,
and full WebDriver/BiDi conformance are outside the verified scope.

See the repository README and compatibility record for examples and details.
